# Judicium

Judicium is an investigative workspace for sanctions, politically exposed persons, and legal-entity lookup.

Investigate entities across sanctions lists, PEP registries, legal opinions, and open-source intelligence from a single authenticated workspace.

## Start here

- [Judicium](https://github.com/judicium-app/judicium) — core application
- [Website](https://judicium.app)
- [Guide](https://judicium.app/guide)
- [MCP server](https://mcp.judicium.app)
